Dhumateng Para Tiyang Ingkang Sampun Dhawah: Sakpunika Rawuhipun Pangadilan Paduka!

Saking Yeshua HaMashiach:

Para tiyang ingkang sampun Kula timbali, Kula pilih, saha ingkang setya, pirengna Sabda saking Gusti paduka ingkang gesang saha juru wilujeng, inggih punika Yeshua Sang Mesias! Bangsa-bangsa papan paduka manggèn saha sajarah ingkang sampun dipunwucalaken déning para pendhidhik Jesuit paduka punika minangka latar saking apus-krama ageng, ingkang pambikakanipun sampun caket saha sampun lumampah, ing pundi para tiyang ingkang sampun dhawah badhé katingal kados déné mahluk asing ingkang saé manahipun, nanging sejatosipun punika para malaékat ingkang sampun dhawah lan awon. Punapa ingkang sampun kalampahan? Inggih punika ingkang badhé kalampahan: lan punapa ingkang sampun katindakaken? Inggih punika ingkang badhé katindakaken: lan boten wonten prekawis énggal ing sangandhaping surya.

Sétan sampun nawèkaken kawruh ingkang dipunsebat majeng wiwit saking wiwitan, inggih punika kawruhipun bab saé lan awon. Piyambakipun punika ahli manipulasi saha juru goroh ingkang sampun ngwucalaken kathah prekawis dhumateng manungsa ingkang boten dipunkersakaken déning Yahweh, amargi punika margining pejah. Titahipun Yahweh boten kadamel kanggé dipunmanipulasi kanggé panguwaos pribadi lan kauntungan utawi minangka sarana kanggé oncat saking pangadilanipun Gusti Allah, utawi kanggé netepaken cara lan tatananipun piyambak. Amargi Sétan sampun ngrusak manungsa wiwit saking wiwitan, lan piyambakipun sampun ngrusak para pengawas ingkang sampun dhawah ingkang ndhèrèk pambrontakanipun.

Dhuh, paduka satru ageng saking sedaya kaleresan, inggih paduka para Sétan: dosa-dosa wiwitan paduka sampun kacathet déning Henokh sang juru tulis wiwit jaman rumiyin, lan cathetan punika taksih wonten ngantos dinten punika, amargi dosa-dosa paduka sampun kacathet. Mila Kula badhé ngringkes, amargi paduka sampun nindakaken prekawis-prekawis punika, lan langkung kathah malih ingkang sampun paduka tindakaken: Paduka sampun nasaraken sedaya putra-putranipun Gusti Allah, lan ngandhapaken piyambakipun dhateng bumi, saha nasaraken piyambakipun lumantar para putri manungsa. Paduka sampun maringaken pitedah awon dhumateng para putra sucinipun Gusti Allah, lan nasaraken piyambakipun saéngga najisaken badanipun kaliyan para putri manungsa. Paduka sampun nedahaken dhumateng para putra manungsa sedaya jotosan pejah, lan nasaraken Hawa, saha nedahaken gegaman pejah dhumateng para putra manungsa: tamèng lan rasukan perang, lan pedhang kanggé perang, saha sedaya gegaman pejah dhumateng para putra manungsa. Lan saking asta paduka, gegaman punika sampun lumampah nglawan para tiyang ingkang manggèn ing bumi wiwit dinten punika lan salaminipun.

Paduka para Sétan sampun ngwucal para putra manungsa bab pait lan legi, lan paduka sampun ngwucalaken sedaya wewadi kawicaksananipun. Paduka sampun paring pitedah dhumateng manungsa bab nyerat mawi mangsi lan kertas, lan amargi punika kathah ingkang damel dosa wiwit jaman kalanggengan ngantos dinten punika. Amargi manungsa boten katitahaken kanggé ancas kados makaten, kanggé paring paseksi dhumateng imanipun ingkang saé mawi péna lan mangsi. Amargi manungsa katitahaken persis kados para malaékat, kanthi ancas supados tetep suci lan leres; lan pejah, ingkang ngrisak sedayanipun, mesthinipun boten saged nguwaosi piyambakipun, nanging lumantar kawruh punika piyambakipun sami sirna, lan lumantar panguwaos punika, kawruh punika ngremuk manungsa.

Paduka para Sétan sampun nedahaken dhumateng para putra manungsa sedaya jotosan awon saking roh-roh lan dhemit, lan jotosan jabang bayi ing guwa garba, supados saged gugur, lan jotosan jiwa, cokotan sawer, lan jotosan ingkang dumados nalika panas ing wanci tengange, putraning sawer ingkang nama Tabââ'ĕt. Amargi paduka malah nyuwun dhumateng Mikhaèl supados nedahaken asma ingkang sinengker, supados paduka saged ngucapaken ing salebeting sumpah, saéngga para tiyang ingkang mbikak sedaya wewadi dhumateng para putra manungsa saged gemeter ing sangajenging asma lan sumpah punika.

Amargi paduka sampun njalari para pengawas ndhèrèk pambrontakan paduka nalika paduka saya ngrusak manungsa. Mila dosa-dosanipun para pengawas sampun kacathet déning Henokh sang juru tulis, lan Kula badhé ngringkes kados makaten: Piyambakipun ngwucal manungsa damel pedhang, lan lading, lan tamèng, lan rasukan perang, lan nepangaken dhumateng piyambakipun logam-logam bumi lan seni ngolahipun, lan gelang, lan rerenggan, lan ginanipun antimon, lan ngéndahaken tlapukan mripat, lan sedaya jinis watu aji, lan sedaya jinis pawarna. Piyambakipun ngwucalaken japa mantra, lan motong oyod, cara mbatalaken japa mantra, astrologi, rasi lintang, kawruh bab méga, tandha-tandha bumi, tandha-tandha surya, lan lakuning rembulan.

Mila lumantar karisakan lan goroh paduka, paduka sampun ngregedi titahipun Yahweh mawi cara-cara awon lan nistha ingkang ngina. Paduka sampun nasaraken manungsa lan damel dosa dhumateng Yahweh, lan paduka sampun nindakaken kalepatan dhumateng manungsa, malah damel dosa dhumateng peksi, lan kéwan galak, lan reptil, lan ulam, lan dosa-dosa paduka mbekta pangadilan ageng ingkang boten badhé saged paduka pulihaken. Paduka sampun ngregedi titahipun Yahweh mawi tèknologi lan manipulasi paduka, lan njalari manungsa gumun dhumateng tipu daya lan goroh paduka. Amargi Yahweh namung nedahaken dhumateng paduka wewadi-wewadi tanpa aji saking titahipun lan nyimpen wewadi-wewadi ingkang paling aji ing salebeting manahipun, tebih saking pangkhianatan paduka.

Paduka para tiyang awon sampun ngwucalaken cara-cara tanpa aji paduka dhumateng manungsa nalika piyambakipun tangkar-tumangkar ing salumahing bumi, lan paduka sampun mbekta kasangsaran lan karisakan ageng lumantar rancangan lan tèknologi awon paduka. Amargi paduka rawuh boten sanès kanggé nyolong, matèni, lan ngrisak. Paduka ngwucalaken manipulasi hawa, amargi paduka punika pangéraning panguwaos hawa, amargi paduka ngapusi aithēr. Amargi nalika Kain damel dosa, piyambakipun yasa kitha; lan paduka sampun ngwucalaken dhumateng manungsa wewadi-wewadi lan manipulasi tanpa aji paduka. Kitha-kitha punika dipunginakaken kanggé ngontrol lan manipulasi saha kanggé mbekta karisakan manungsa, kados déné paduka ngginakaken kitha-kitha punika kanggé damel nistha-nistha karisakan paduka.

Paduka sampun njalari bangsa nglawan bangsa ing salebeting perang lan pasulayan tanpa wates, lan paduka sampun njalari umat Kula damel dosa, lan Yahweh sampun mbuyaraken Suku-suku Israel dhateng sekawan penjuru angin. Boten dados prekawis, niat awon paduka sampun majengaken ancasipun Yahweh, amargi kanthi pambuyaranipun, pangempalan wedhus-wedhus ingkang kantun badhé kalampahan. Lan Kula badhé ngutus kalih seksi Kula kanggé medhar wangsit 1260 dinten kanthi ngagem sandhangan bagor. Ing salebeting sedaya upados paduka kanggé ngrisak para putranipun Yahweh, paduka sampun gagal total, lan paduka boten saged mangertos bilih upados paduka malah majengaken ancasipun Yahweh, amargi malah para satrunipun nggih mituhu dhumateng swantenipun.

Amargi paduka sampun nganiaya lan ngganggu 12 suku ing saindenging bumi nalika paduka ngupados karisakanipun. Paduka sampun nyolong laré-laré saking para ibu, lan mendhet laré-laré saking kulawarga saha mindhahaken piyambakipun ing saindenging bumi, lajeng ngapusi piyambakipun lan njalari piyambakipun pitados dhumateng dongèng-dongèng Jesuit babagan sajarah, ancas, lan asal-usulipun ingkang sejati. Boten dados prekawis, paduka sampun gagal, amargi Kula, Yeshua HaMashiach, badhé nyambungaken malih piyambakipun kanthi jangkep kaliyan masa lalu, bangsa, lan warisan sejati, lan Kula badhé ndadosaken sedaya ahli waris kaslametan dados satunggal manungsa énggal, inggih ing salebeting Kula, Kristus Yesus.

Kanthi sulapan lan karisakan ageng, paduka sampun kanthi pinter ndhelikaken tèknologi paduka, malah ngucapaken goroh bilih tiyang-tiyang jaman rumiyin punika bodho lan boten gadhah tèknologi. Amargi paduka sampun nedahaken dhumateng para leluhur wewadi-wewadi tanpa aji paduka, lan boten wonten prekawis énggal ing sangandhaping surya. Mila paduka ndhelikaken kaleresan babagan manipulasi paduka dhumateng titah, malah ndhelikaken saking para tiyang ingkang badhé paduka rayu mawi apus-krama ageng paduka. Paduka sampun ngenalaken malih trik-trik sihir paduka, kados déné paduka sampun nyamektakaken panggung supados saged nyamar dados mahluk asing. Lan lumantar invasi mahluk asing palsu paduka, paduka badhé njalari sedaya tiyang gumun dhumateng tandha-tandha lan kaélokan goroh paduka, malah para tiyang ingkang namanipun boten kaserat ing Kitab Kagesangan wiwit dhasaring jagad. Nanging Kula, Yeshua HaMashiach, badhé mbikak wewadi paduka ngantos tuntas, lan saben wewadi ingkang sinengker badhé katingal ing pepadhang.

Lah! Kula badhé ngrebat para tiyang Kula ingkang setya dhateng swarga, amargi Kula rawuh kanggé Manten Putri Kula lan Kula boten saged dipunendheg. Lan Kula, Yeshua HaMashiach, rawuh kanggé ngadili lan perang saha mbekta pangadilan ageng ing bumi, lan paduka boten badhé saged oncat.

Kula, Yeshua HaMashiach, Gustining para gusti lan Ratu ning para ratu, sampun ngutus sabda-sabda punika lumantar abdi Kula, lan lumantar abdi Kula sabda-sabda Kula sampun kautus, lan sedayanipun badhé kalampahan.

Saking Yahweh, Gusti Allah Langgeng Ingkang Maha Agung:

Dhuh, paduka para Sétan, paduka sampun ngapusi titah Kula supados ndhèrèk tandha-tandha lan kaélokan goroh paduka, lan bebendu Kula panas dhumateng paduka. Umat Kula badhé kapisahaken babar pisan saking alang-alang paduka ingkang sampun paduka sebar ing antawisipun gandum Kula ing taman sih-rahmat Kula; lan Putra Kula, Kristus Yesus, badhé ngempalaken gandum Kula ing lumbung Kula, lan mila Gustining panèn badhé ngempalaken, nalèni, lan ngobong alang-alang paduka. Pangadilan ageng tumedhak dhumateng paduka, lan paduka boten badhé saged oncat saking asta Kula. Wiwit saking wiwitan, paduka ngrayap lan ndhelik ing antawisipun para putra Kula, malah ngrusak para tiyang alit Kula wiwit saking wiwitan mawi goroh lan tipu daya paduka.

Paduka sanès déwa, lan para tiyang ingkang ndhèrèk apus-krama lan angen-angen kemenangan paduka nggih sanès déwa. Paduka boten saged nitahaken, amargi paduka boten gadhah panguwaos, lan Kula boten naté nitahaken paduka kanthi kabisan kados makaten amargi Kula sampun mangertos bilih paduka badhé mbaléla sadèrèngipun katitahaken; lan ing salebeting kaadilan lan katresnan Kula, Kula nitahaken paduka ing kaleresan, lan paduka sampurna ing dinten paduka katitahaken. Ing salebeting umuk tanpa aji paduka, paduka ngegung-egungaken kaagungan paduka piyambak, nanging paduka boten gadhah kaagungan, lan Kula badhé mbikak wewadi paduka kanthi tuntas minangka juru apus. Kula badhé masrahaken paduka ing sangajenging para Ratu, lan piyambakipun badhé ningali paduka lan sepinten tanpa dayanipun paduka. Putra Kula, Yeshua HaMashiach, sampun ngawonaken paduka kanthi tuntas ing Calvary, lan paduka boten gadhah pangajeng-ajeng.

Paduka namung dipunidinaken nindakaken punapa ingkang Kula idinaken, amargi paduka punika satru ingkang sampun kawon. Paduka nyolong serat hak milik bumi kanthi tipu daya lan goroh dhumateng Adam, lan sakpunika putra ontang-anting Kula, inggih punika Yeshua HaMashiach, sampun ngawonaken paduka ing salebeting katresnanipun dhumateng Kula lan titah Kula; lan bumi punika kagunganipun, inggih kagunganipun Gustining para gusti lan Ratu ning para ratu, amargi Kula sampun ngandika makaten. Amargi piyambakipun sampun nebus bumi lan manungsa mawi rah sucinipun piyambak, lan para tiyang ingkang milih gesang badhé katebus. Sedaya pakaryan tanpa aji paduka badhé dipunicalaken, lan sedaya ingkang milih gesang badhé medal saking goroh lan tipu daya paduka dhateng gesang énggal, lan Kula badhé ndadosaken para tiyang setya langkung mulya tinimbang paduka rumiyin. Amargi paduka sampun gagal, dhuh para pangéran bumi ingkang ringkih lan mlarat, malah saben pangéran ing tatanan paduka sampun gagal sesarengan kaliyan paduka, dhuh sawer ingkang ngrayap lan goroh.

Sakpunika sampun dumugi wekdalipun Pangadilan paduka lan karisakan total krajan paduka, inggih punika krajan ingkang sampun paduka yasa ing salebeting upados kanggé ndhelikaken Kula, inggih Yahweh, saking titah Kula. Paduka boten badhé saged oncat. Paduka boten badhé naté mlebet swarga malih, amargi paduka sampun kabucal dhateng bumi lan boten badhé wangsul, lan papan paduka boten wonten ing swarga malih. Paduka katali ing bumi ingkang paduka péngini, ingkang sanès hak paduka kanggé dipunrebat. Saben pakaryan paduka badhé dipunicalaken ing gesangipun para tiyang ingkang paduka upados risak (lan ing bumi piyambak); piyambakipun badhé manggèn ing katentreman lan kaslametan salaminipun, lan kabingahan sampurna badhé dipungadhahi, lan Kula badhé manggèn ing antawisipun manungsa lan Kula badhé dados Gusti Allahipun.

Nanging paduka, dhuh ingkang ngrayap, tanpa daya ing pandeleng Kula, lan paduka boten saged nindakaken punapa-punapa kanggé ngendhegaken Kula. Ing enem dinten wiwit dhawahipun manungsa, amargi sedinten punika sewu taun ing pandeleng Kula, paduka boten ngasilaken punapa-punapa kejawi pangadilan, paukuman, karisakan, lan siksa kanggé paduka lan sedaya ingkang ndhèrèk. Amargi paduka badhé katali lan kabucal dhateng tlaga geni ageng ing pundi Kula sampun damel latu ingkang paling panas kanggé paduka, inggih punika latu biru murni, lan paduka badhé kobong salaminipun, lan Kula badhé males saben pakaryan awon ingkang naté paduka tindakaken, tikel-matikel. Paduka sampun matèni mayuta-yuta tiyang, lan paduka badhé mbayar saben jiwa ingkang sampun ical, lan paduka boten badhé naté oncat. Paduka badhé mangertos sedaya dosa ingkang paduka tindakaken, lan paduka boten badhé naté oncat saking pangadilan, lan paduka badhé disiksa salaminipun amargi dosa-dosa ingkang sampun paduka tindakaken. Paduka badhé mangertos kanthi jangkep dosa-dosa lan kalepatan paduka ing salebeting siksa paduka, lan para tiyang ingkang paduka sengiti badhé pikantuk kemenangan pungkasan nglawan paduka. Lan sedaya tiyang ingkang boten leres ingkang naté paduka rayu kanggé damel dosa lan ndhèrèk pambrontakan paduka, malah para tiyang ingkang namanipun boten naté kaserat ing Kitab Kagesangan, badhé ndhèrèk ing siksa paduka. Paduka sedaya badhé mbayar saben dosa ingkang sampun paduka tindakaken, amargi paduka sampun damel dosa dhumateng Yahweh lan dhumateng titah Kula, lan Kula badhé males. Amargi ing salebeting kaadilan Kula, Kula badhé males dosa-dosa, tumindak, lan cara-cara awon paduka kanthi jangkep wangsul dhateng dhadha paduka tikel-matikel lan kanggé salaminipun. Lan Kula, Yahweh, inggih Gusti Allah langgeng ingkang maha agung, sumpah prekawis-prekawis punika kanthi asma Kula piyambak, amargi Kula boten saged sumpah kanthi asma ingkang langkung agung.

Paduka badhé ngladosi ancas Kula, lan ing salebeting sengit lan karisakan paduka, paduka badhé nggiring para pilihan Kula dhateng Kula; amargi Kula badhé nuntun piyambakipun kanthi astanipun Yeshua HaMashiach lan tentaranipun para tiyang prakosa, amargi piyambakipun badhé ngempalaken wedhus-wedhus Kula ingkang kantun. (Lah! 144.000 ingkang kautus déning Yeshua HaMashiach badhé nindakaken pakaryan-pakaryan ageng ing sangajenging kadurjanan nistha paduka.) Lan boten wonten setunggal kémawon ingkang sampun Kula tetepaken kanggé gesang langgeng badhé dhawah ing rancangan paduka, amargi piyambakipun boten saged dipunrebat saking asta Kula, lan boten wonten ingkang saged ngrebat piyambakipun saking astanipun Putra Kula: Amargi Kula sampun maringi piyambakipun asma ing sanginggilipun saben asma, lan piyambakipun rawuh ing panguwaosipun Yahweh piyambak, amargi Kula sampun ngedum dhampar Kula kaliyan piyambakipun. Lan piyambakipun badhé ngremuk sirah paduka kanthi tuntas. Paduka sampun gagal, pangéran alit, lan wekdal paduka sampun dumugi.

Kula, Yahweh, Gusti Allah langgeng ingkang maha agung, sampun ngutus sabda-sabda punika lumantar abdi Kula, lan lumantar abdi Kula sabda-sabda Kula sampun kautus, lan sedayanipun badhé kalampahan. Amargi Yahweh, Gusti Allah langgeng ingkang maha agung, sampun ngandika makaten, lan boten wonten ingkang saged mbatalaken pangandika Kula. Kula punika El Shaddai!
