Bumi punika Kagunganipun Gusti!

Bumi saisinipun punika kagunganipun Gusti: Sanadyan si perampas lan si maling sampun ngakeni gadhah hak, piyambakipun namung saged nindakaken punapa ingkang sampun dipun paringaken déning Rama Kula kanggé katindakaken ing astanipun wonten ing rancangan panebusan-Ipun ingkang suci kanggé umat manungsa. Sampun ajrih dhumateng piyambakipun! Piyambakipun kedah lajeng wonten ing sawatawis wekdal, amargi wekdalipun sampun dumugi; nanging sampun ajrih dhumateng piyambakipun, hé para tiyang Kula ingkang mursid lan setya; sampun ajrih dhumateng piyambakipun! Punapa Kula boten sampun maringi kamenangan dhumateng panjenengan nglangkungi piyambakipun? Kasangsaranipun Yakub punika sanès kanggé para tiyang Kula ingkang setya, lan tiyang-tiyang ingkang sampun sowan dhumateng Kula ing wekdal-wekdal pamulihan badhé kaluhuraken sanget wonten ing dhampar dalem Allah piyambak. Saèstu, hé umat Kula ingkang setya, ganjaran ageng sampun kasimpen kanggé panjenengan amargi kasetyan panjenengan ingkang sampun panjenengan ketingalaken kanthi setya dhumateng Kula.

Kula sampun ndadosaken panjenengan para raja lan para imam kanggé Kula wonten ing Kraton Kula ingkang badhé rawuh lan wonten ing ngarsanipun Rama kita, mila mugi kiyat ing panandrem, hé para putra Kula, ing menit-menit pungkasan saking jam pungkasan punika. Rawuh Kula sampun celak, lan panebusan panjenengan sacelak napas panjenengan salajengipun, mila mugi kiyat ing kasetyan wonten ing ngarsa Kula, kanthi mangertos bilih Kula punika kakiyatan lan kaslametan panjenengan lan panjenengan sampun kaségel wonten ing Kula, amargi Kula sampun numbas panjenengan kanthi rah Kula nalika Kula masrahaken gesang Kula kanggé panjenengan supados panjenengan saged karukunaken ing katresnan dhumateng Rama kita ing swarga. Kula ngajeng-ajeng dinten punika, lan Rama kita ngajeng-ajeng dinten punika, nalika panjenengan jumeneng ing ngarsanipun kanthi badan ingkang sampun Kula siyapaken kanggé panjenengan wonten ing panebusan panjenengan ingkang sampurna, lan boten badhé wonten malih ipat-ipat dhumateng para pilihan Kula.

Dhuh, manungsa, sinten ta panjenengan punika déné wani-wani ngakeni warisan Kula? Punapa panjenengan boten mangertos bilih Kula sampun numbas bumi saisinipun kanthi rah Kula piyambak ingkang tanpa dosa? Bumi saisinipun punika kagunganipun Gusti, lan kabeneran badhé rawuh ing bumi! Sanadyan panjenengan badhé ngrisak bumi lan ndadosaken papan panggenan ingkang sepi kanggé piawon-piawon panjenengan ingkang nistha, sanadyan panjenengan badhé sumpah setya dhumateng satru langgeng Kula lan ngupados kasangsaran panjenengan piyambak kanggé kauntungan kadonyan ingkang asor, panjenengan boten mangertos bilih panjenengan saweg merangi jiwa panjenengan piyambak nalika panjenengan ngempalaken bebendu kanggé dinten bebendu, nalika Kula badhé maringi piwales dhumateng saben tiyang miturut pakaryanipun.

Dhuh, manungsa bodho, panjenengan wicanten ing manah panjenengan bilih para déwa panjenengan badhé nylametaken panjenengan, mangka déwa-déwa wau boten gadhah ganjaran kanggé panjenengan, lan panjenengan sampun kapusan lan mitenah tiyang sanès ing salebeting angen-angen panjenengan. Para déwa panjenengan ingkang kadamel saking séla boten saged wicanten; para brahala ing manah panjenengan boten saged mireng; déwa-déwa wau boten saged nylametaken panjenengan, dhuh tiyang ingkang nyembah brahala! Langkung saé kanggé panjenengan manawi panjenengan boten naté kalairaken, amargi bebenduning Allah mapan ing panjenengan amargi watak panjenengan ingkang wangkot. Sanadyan tutuk panjenengan sampun dados kuburan ingkang menga, ngedalaken tembung-tembung ageng nglawan Gustining para Gusti, tembung-tembung panjenengan badhé wangsul dhumateng panjenengan, lan pepénginan panjenengan ingkang awon badhé katumplekaken dhumateng panjenengan wonten ing paukuman langgeng panjenengan ingkang badhé rawuh. Dhuh, manawi kémawon panjenengan purun mèngèng dhumateng Kula lan nampi kaslametan saking kawontenan panjenengan ingkang sampun dhawah. Dhuh, manawi kémawon panjenengan namung ngakeni asma Kula kanthi lambé panjenengan ingkang goroh. Nanging boten, panjenengan sampun tresna dhumateng goroh panjenengan, lan panjenengan sampun tresna dhumateng angen-angen panjenengan, lan panjenengan sampun ngédol jiwa panjenengan dhumateng karisakan langgeng kanggé roti sacuwil ingkang boten saged nyekapi panjenengan; amargi Kula punika roti gesang! Bilai panjenengan badhé dumugi kanthi dadakan lan tanpa tamba. Saèstu, kathah saking panjenengan ingkang malah boten pitados bilih Kula naté rawuh lan ngwutahaken rah panebusan Kula kanggé dosa-dosa lan kaslametanipun umat manungsa. Langkung saé manawi panjenengan boten naté kalairaken, amargi bebendu ingkang sampun panjenengan kempalaken kanggé jiwa panjenengan piyambak badhé dumugi tanpa tamba, lan panjenengan badhé mangertos kanthi cetha dosa-dosa panjenengan, lan kasangsaran sarta karisakan panjenengan ingkang sampurna badhé dados jodho panjenengan. Panjenengan badhé nedha rereged panjenengan piyambak, lan tumindak panjenengan ingkang reged badhé tansah nunggil kaliyan panjenengan, nalika panjenengan kapendhem ing wohing bebendu ing salebeting tumindak awon panjenengan ingkang sampun panjenengan lampahi kanthi piawon ageng nglawan asma Kula. Sumingkira saking Kula; Kula boten wanuh kaliyan panjenengan!

Kados pundi panjenengan saged wicanten makili Kula mangka panjenengan boten wanuh kaliyan Kula? Dhuh tiyang bodho! Sumingkira saking Kula, amargi Kula boten naté wanuh kaliyan panjenengan!
